# CBPS Density Estimators Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pure-Python CBPS (binary ATE/ATT, multi-valued, continuous) density estimators in `skcausal.density.cbps`, validated against the R `CBPS` package.

**Architecture:** Numpy/scipy fitter functions operating on the SVD-orthonormalised design (`_multinomial.py`, `_binary_att.py`, `_continuous.py`) return a `CBPSResult`; two `BaseDensityEstimator` subclasses (`CBPSCategorical`, `CBPSContinuous`) wrap them with the `DesignStandardizer` and level encoding. R fixtures (JSON) are generated once by an R script and committed.

**Tech Stack:** numpy, scipy.optimize (BFGS, bounded Brent), polars/pandas conversion via `skcausal.datatypes`, pytest, R + CBPS (fixture generation only).

**Spec:** `docs/superpowers/specs/2026-08-25-cbps-design.md`

## Global Constraints

- Pure Python: only numpy/scipy (scipy is already a transitive dependency via scikit-learn); no R at test time.
- Follow `BaseDensityEstimator` contract: `_fit(X, t)`, `_predict_density(X, t)`, tags `capability:t_type`, `density_kind`, `get_test_params`.
- `sd`/`var` use ddof=1, probabilities clipped at 1e-6, scale search interval [0.8, 1.1], as in R.
- Run tests with `uv run pytest`.
